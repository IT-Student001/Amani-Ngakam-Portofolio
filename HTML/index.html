ABOUT ME

Building, learning,
and always improving.

I'm Amani, a student and developer who enjoys building things with technology. I spend a lot of my time experimenting with programming, web development, software, game development, and creative digital projects.

I became interested in programming because I wanted to understand how the things I use every day actually work. Instead of only using technology, I started creating my own projects and learning how different parts of software connect together.

I usually start a project with an idea or a drawing of what I want the final result to look like. From there, I build the structure, create the visual design, add functionality, and keep refining everything until it works the way I imagined.

I'm especially interested in web development. I enjoy working with HTML, CSS, and JavaScript to create interfaces that are clean, responsive, interactive, and enjoyable to use.

Outside of web development, I work on software, game development, AI experiments, and other programming projects. I enjoy projects where programming and creativity can be combined into something that actually works.

I also type at around 150 words per minute. Fast typing helps me move quickly when I'm writing code, documenting ideas, researching, or working through large projects.

When I build something, I don't want to simply copy code and have it work. I want to understand why it works. Organize my projects, test the code, find problems, and decide how everything should work together.

I'm constantly learning new technologies and challenging myself with projects that are more complicated than the ones I built before. My goal is to keep improving my programming, design, hardware, and problem-solving skills while continuing to turn ideas into real projects.
