PROCESS

How I build.

01

Concept

I start with a drawing or rough idea of what I want the website to look like. I research existing websites, take inspiration from them, and then add my own ideas.

02

Design

I build the visual style using CSS and create the HTML structure around the layout, components, and styling I want.

03

Development

I add functionality using JavaScript and, depending on the project, other technologies such as Java, PHP, SQL, or Python.

04

Refine

I go back through the project, test everything, fix small issues, improve the design, and keep refining it until everything works and looks right.
